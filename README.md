# 🏗️ Bomman Construtora — Website Institucional

Este é um projeto desenvolvido para a Bomman Construtora, empresa especializada em obras residenciais e comerciais, que atua com foco em qualidade, transparência e eficiência.

O site foi construído com HTML, CSS e JavaScript puro, buscando uma navegação leve, responsiva e moderna, apresentando os serviços, projetos e diferenciais da empresa.

## 💡 Objetivo do Projeto

O principal objetivo foi criar um site institucional completo que refletisse a identidade e o padrão da Bomman Construtora.
A ideia foi desenvolver um layout limpo e direto, priorizando:

Responsividade (funciona perfeitamente em desktop, tablet e mobile);

Animações e carrosséis suaves, sem comprometer o desempenho;

Design profissional e confiável, de acordo com o segmento de engenharia civil e construção.

🧩 Tecnologias e Ferramentas Utilizadas

HTML5 → Estrutura do site e organização semântica das seções;

CSS3 → Estilização completa, com foco em responsividade, grid e tipografia;

JavaScript (Vanilla JS) → Interatividade do menu, carrosséis e botões dinâmicos;

Slick Carousel → Biblioteca JS leve utilizada para criar os carrosséis de projetos e depoimentos;

Font Awesome / Ícones SVG → Ícones vetoriais modernos e escaláveis;

Animações com Transições CSS → Efeitos sutis e suaves para melhorar a experiência do usuário.

## ⚙️ Funcionalidades Implementadas

Menu Responsivo (Hambúrguer) — Abre e fecha suavemente em telas pequenas, incluindo clique fora do menu para fechamento.

Carrosséis Dinâmicos — Exibição de projetos e depoimentos de forma interativa, adaptável a cada resolução.

Botão Flutuante do WhatsApp — Facilita o contato direto com a empresa.

Botão “Voltar ao Topo” — Aparece automaticamente após rolar a página e leva suavemente ao topo.

Layout 100% Responsivo — Ajuste automático para desktop, tablet e celular.

## 🎨 Destaques de Design

O layout foi pensado para transmitir credibilidade e sofisticação, com tons escuros que reforçam a marca da empresa e contrastam com os botões de ação em verde e branco.
A tipografia, espaçamentos e ícones foram cuidadosamente ajustados para uma leitura agradável e uma navegação intuitiva.
